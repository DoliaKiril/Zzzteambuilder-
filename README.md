- **49 S-Rank (5★) агентов** (включая Феникс Реффаэллу и Севериана Лоуэлла из 3.3) с кнопкой «?» возле каждого стата и подробными формулами капов.

- **28 Эндгейм-Боссов** (*Опасный штурм / Deadly Assault*, *Беспощадная охота / Notorious Hunt*, *Оборона Шиюй / Shiyu Defense*, *Нулевая каверна / Затерянная бездна*) с разбором новых механик **Помощи в защите / уклонении**, **Цепного парирования (`×`)**, **Навыка контроля и Подавления (Control Skill → Shutdown)**, **Щита миазмов**, **Барьера скверны**, получения **5000 очков эффективности** и загрузкой рекомендуемых пачек в 1 клик.

## Автоматическая сборка Android `.apk` через GitHub Actions
1. Загрузите все файлы из этого архива в корень вашего GitHub-репозитория (включая папку `.github/workflows/build.yml`).
2. Перейдите во вкладку **Actions** → запустится workflow **Build ZZZ Synergy Android APK**.
3. Через 2 минуты скачайте готовый артефакт **ZZZ-Synergy-Helper-APK** (`app-debug.apk`).
