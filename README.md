# 🎮 ZZZ Phaethon OS v3.3 — Модулятор Отрядов и Гайды

Автономний тактичний помічник, калькулятор синергій загонів та енциклопедія для **Zenless Zone Zero** (до патчу 3.3).

---

## 📁 Структура репозиторію

- `index.html` — основний веб-інтерфейс (8 вкладок, Liquid Glass UI, рушій синергій та калькулятор сабстатів).
- `db_agents.js` — база 47 S-Rank агентів (стати, скейли, гайди, ротації).
- `db_equipment.js` — база 30 Драйв-дисків та 85 Ампліфікаторів (5★ і 4★).
- `db_mechanics.js` — розбір 11 ключових механік ZZZ з формулами.
- `db_bosses.js` — тактики 9 босів Каверн та Нульової Каверни з таймінгами парирування.
- `.github/workflows/build.yml` — GitHub Actions воркфлоу для автоматичної збірки готового `.apk` на Android.

---

## 📱 Як зібрати Android APK без комп'ютера (через телефон):

1. Завантаж вміст цього репозиторію у свій GitHub-репозиторій `DoliaKiril/Zzzhelper`.
2. Перейди у вкладку **Actions** у своєму репозиторії на GitHub.
3. Після завантаження файлів воркфлоу **Build ZZZ Synergy Android APK** автоматично запуститься і відпрацює приблизно за 2-3 хвилини.
4. Після успішного завершення (зелена галочка ✅) прогортай вниз до розділу **Artifacts**.
5. Натисни на **ZZZ-Synergy-Helper-APK**, завантаж архів, розпакуй файл `app-debug.apk` і встанови на свій Android-смартфон!
